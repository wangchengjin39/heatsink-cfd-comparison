# 结果复核与 Fluent 算例说明

## 从公开数据复核报告

在仓库根目录运行 `python analysis/verify_results.py`。脚本使用 Python 标准库，从两张 CSV 重新计算结果。

- [`data/case_summary.csv`](../data/case_summary.csv) 汇总三组已保存算例的单元数、迭代步数、热模块最高静温、两个截面的质量加权总压、进出口质量流量及空气净带走热量。温度和压降来自 Fluent 报告。进出口质量流量和热流来自保存的 Fluent 面数据，两列质量流量均用正数表示流量大小。
- [`data/dense_v2_iterations_250_300.csv`](../data/dense_v2_iterations_250_300.csv) 来自密排第二版的 Fluent 合并报告文件，包含第 250–300 步。第 250 步是续算起点，之后新增 50 步。所有温度列用 K，压强列用 Pa。

鳍片段总压降为 `pt_fin_in_pa − pt_fin_out_pa`。最后 20 步分别对最高温度和**逐步计算的压降**取最大值减最小值。温度差以 K 或 °C 表示时数值相同。质量流量相对不平衡以入口质量流量为分母，能量相对偏差以 200 W 热负荷为分母。

验收时，`dense_v2` 应显示 194,892 个单元、第 300 步、107.32 °C 和 47.25 Pa。第 281–300 步的温度和压降波动幅度分别约为 0.002099 °C 和 0.001177 Pa。

## 在 Fluent 中读取已保存的解

算例压缩包包含下列目录和文件。每组文件放在同一目录，以 Ansys Fluent 2026 R1 Student 的三维双精度求解器读取。

| 压缩包目录 | Case | Data | 保存步数 |
| --- | --- | --- | ---: |
| `dense_v1/` | `FFF-4.cas.h5` | `FFF-4-00150.dat.h5` | 150 |
| `wide_v1/` | `FFF-6.cas.h5` | `FFF-6-00150.dat.h5` | 150 |
| `dense_v2/` | `dense_v2_final_iter300.cas.h5` | `dense_v2_final_iter300.dat.h5` | 300 |

1. 启动独立 Fluent，用「文件 → 读取 → Case」载入所选算例的网格和设置，再用「文件 → 读取 → Data」打开配套求解数据。
2. 在控制台运行 `/mesh/size-info` 核对单元数。打开「报告定义」，对 `model_tmax`、`pt_fin_in` 和 `pt_fin_out` 分别点「计算」。第二版第 300 步的两截面总压约为 84.570911 Pa 和 37.317030 Pa。
3. 需要核对平衡时，在流量报告中选真实风道外边界 `inlet` 和 `outlet`，分别查质量流量和总传热率。以两侧净流量核对质量守恒，以净热量与 200 W 的差核对能量平衡。

压缩包的 `SHA256SUMS.txt` 记录六个原始结果文件的 SHA-256。这里的复核从保存的网格和求解场开始。模型尺寸、条件和结论适用范围见[项目报告](../README.md)。
